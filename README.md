## Ответы на контрольные вопросы

### 1. В чём разница между полем класса и обычной переменной в функции?
Обычная переменная внутри функции создается в момент вызова этой функции и сразу же уничтожается (стирается из памяти), как только функция завершит работу. Она локальна. 
Поле класса (оно же свойство объекта) принадлежит самому объекту. Оно живет в памяти всё то время, пока существует сам объект, и к нему можно обращаться из любых методов этого класса в любой момент. По сути, поле хранит состояние конкретного объекта.

### 2. Что такое конструктор и зачем он нужен?
Конструктор — это специальный метод класса, который автоматически вызывается в самый момент создания нового объекта (через ключевое слово, либо просто по имени класса в Dart). 
Нужен он для того, чтобы правильно инициализировать объект: передать в него начальные данные (например, название задачи), задать дефолтные значения для полей (например, `isDone = false`) и подготовить объект к работе, чтобы компилятор не ругался на пустые переменные.

### 3. Зачем нужен @override перед toString()? Что будет если его убрать?
Аннотация `@override` подсказывает компилятору, что мы намеренно переписываем (переопределяем) метод `toString()`, который наш класс унаследовал от базового класса `Object`. 
Если её убрать, код всё равно скомпилируется и будет работать, но `@override` — это отличная защита от опечаток. Если я случайно напишу `toStrng()` с ошибкой, компилятор сразу это заметит и выдаст предупреждение. Без этой аннотации мы бы просто создали новый метод, а стандартный `print(task)` продолжил бы выводить бесполезное `Instance of 'Todo'`.

### 4. Чем статическое поле static int _counter отличается от обычного поля? Сколько копий этого поля существует в программе?
Обычные поля создаются заново для каждого нового объекта — у каждой задачи свой уникальный `id`, свой `title` и свой статус. Статическое поле (`static`) принадлежит не конкретным объектам, а всему классу целиком. 
В программе существует ровно **одна копия** статического поля, сколько бы объектов мы ни создали. Именно поэтому оно идеально подходит на роль глобального счетчика для генерации уникальных ID.

### 5. Что означает нижнее подчёркивание в _counter?
В языке Dart нет привычных ключевых слов `private` или `public`. Вместо этого приватность задается прямо в имени переменной. Нижнее подчеркивание в начале названия `_counter` означает, что это поле является **приватным**. 
Оно доступно только внутри того файла, где объявлено (в данном случае — внутри `lib/todo.dart`). Из других файлов (например, из главного цикла в `bin/lab2_todo.dart`) напрямую изменить или прочитать этот счетчик не получится, что защищает данные от случайной порчи.
